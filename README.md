# Alfred · Codex Assistant for Mac

Alfred 是为 Codex Mac 桌面端制作的个人工作助手：在菜单栏查看周额度和任务状态，在桌面显示额度、日程与待办，用蝙蝠信号提醒需要处理的事情。界面采用黑金 Batman 元素，支持浅色、深色和跟随系统，无独立主窗口。

当前阶段版本：**1.1.1 / build29**。本项目是个人制作的非官方助手，与 OpenAI、Batman 品牌及同名 Alfred 启动器无隶属关系。

## 下载与安装

1. 打开 [Releases 下载页](https://github.com/EntroLi/Alfred-Codex-Assisant-for-Mac/releases/latest)，下载 `Alfred-1.1.1-build29-arm64.zip`。
2. 解压，将 `Alfred.app` 移入 `~/Applications`（用户主目录的“应用程序”文件夹，没有时新建），再打开。菜单栏会出现蝙蝠图标。
3. 这是个人开发、ad hoc 签名的应用，未经过 Apple 公证。若 macOS 阻止打开，请确认下载来源后，在“系统设置 → 隐私与安全性”使用系统提供的“仍要打开”；不要关闭系统安全保护。
4. 需要日程、待办或系统通知时，在 Alfred 对应页面授权。桌面右键 → 编辑小组件 → 搜索 Alfred → 添加横向组件。

**当前安装包适用范围：Apple Silicon（arm64），建议 macOS 14 或更新版本，已安装并登录 Codex Mac 桌面端。** 主程序最低声明 macOS 12，原生组件要求 macOS 14；Intel 安装包和其他系统版本未验收，当前构建脚本的 Widget 目标为 arm64。

仓库的 “Code → Download ZIP” 是源码；可直接使用的应用在 Releases。升级前退出旧 Alfred，只替换同一安装位置的应用，避免同时保留多个 `.app`。版本升级不需要删除个人设置或统计。

## 可以做什么

| 入口 | 功能 |
| --- | --- |
| 菜单栏 | 周剩余额度、未读点；点击打开，再次点击关闭 |
| 概览与用量 | 账户额度、重置时间、本机 token 统计、任务记录与使用节奏 |
| 双向额度轨道 | 金色剩余从左延伸，暖灰周期进度从右延伸；铜橙提示超用，柔金斜纹提示富余 |
| 原生桌面组件 | 横向 4×2：额度、下一场日程、优先待办、当前任务和未读；可选实时桌面贴片 |
| 管家页 | 待处理蝙蝠信号持续保留，直到确认已读；Your dot 入口、本机日报与行动清单 |
| Touch Bar | 额度开关并刷新、管家入口、当前/最近完成对话切换、关闭；只保留短按 |
| 提醒 | 额度使用节奏、低位额度、日程/截止、输入活跃起身提醒 |
| 外观 | 浅色/深色/跟随系统、英文 Comic、中文宋体、玻璃导航及可选桌面陪伴 |

## 数据与权限

- 使用当前用户已登录的 Codex 本地接口读取账户额度，从本机活动日志统计 token 和任务状态。不将 API token 数量换算成精确订阅额度。
- 菜单栏日程／提醒继续只读；新增按需 `--agenda` 手动协作接口支持独立事项的预览、逐批批准与保存回读，不自动同步或修改。未批准的批次不能执行；邀请及重复系列修改不支持；精确单事件删除须明确批准。系统权限拒绝时明确显示，不伪装成“没有事项”。
- 本机数据位于 `~/Library/Application Support/CodexQuotaBar`，沿用兼容标识 `local.codex.quota-bar`。原生 Widget 只读取其中的 `native-widget-v1.json` 显示快照，不读取账户凭据、活动日志或统计缓存。
- 日报基于本机活动、日程、提醒和信号生成，不读取 Your dot 聊天正文，不同步管家空间，不额外调用模型。
- 公开仓库与安装包不包含开发者的会话、日程、提醒内容、个人配置、认证、运行快照或原始本地 Git 历史。

## 1.1.0 手动日历协作

新增标题、时间、位置、所属日历身份保留、备注五字段接口；备注可追加／替换，需精确旧值、差异预览和对应批准。仅日历授权入口与日历＋提醒入口分开，未知结果不自动重放。详见[手动协作说明](docs/日历提醒手动协作.md)。

100项逻辑／模拟测试通过。冻结开发包已有真实日历授权与限目标读取验证，并已有位置／备注保存回读成功记录；一个全天新增出现回读差异，保留unknown且不重放；本安装包是新签名，权限需按系统实际状态确认。该功能供明确批准的手动流程使用，不是自动管家同步。

## 已知限制

- **系统通知左侧应用图标仍可能显示蓝色占位图标，尚未解决。** 右侧重复图片已移除，Batman 文案与面板内信号有效。系统管理通知横幅外框和布局。
- WidgetKit 更新受系统预算控制，不能保证即时刷新。组件显示旧值时先打开 Alfred 刷新；备用贴片随应用刷新。
- 活动状态来自本机日志推断；“一回合完成”不代表整个项目完成。起身提醒按输入活跃计时，不能检测坐姿。
- Codex 接口和路由可能随宿主版本变化。本版主要在开发者的 Mac 验证，其他 Mac 的首次安装、权限和硬件操作仍需实际验证。

## 从源码构建

需要 Apple Command Line Tools（`xcode-select --install`）、可用的 Swift 工具链与 Python 3。现有图标资源可直接构建；完整 Xcode/actool 仅用于后续可选资产目录验证，当前构建不依赖它。

```bash
git clone https://github.com/EntroLi/Alfred-Codex-Assisant-for-Mac.git
cd Alfred-Codex-Assisant-for-Mac
./tools/test.sh
./build_app.sh
```

构建结果在 `.staging/release.*/Alfred.app`，只生成暂存包，不覆盖正在运行的应用。构建后先退出原 Alfred，再将应用复制到同一安装位置。日程授权与 Widget 注册可能需要重新打开应用或组件图库。
